# Nutrielo

Aplicação web que conecta órgãos e estabelecimentos com alimentos excedentes
a famílias e ONGs em situação de vulnerabilidade alimentar.

Projeto da disciplina Engenharia de Software, Fatec Itapetininga (2º semestre/2026).

## Autoras
- Karen Fernanda Muzel Reis
- Laura Assis Andrela

## Tecnologias
HTML, CSS, JavaScript, SQL, GitHub e Vercel.

## Como executar
Abra o arquivo `index.html` no navegador.
